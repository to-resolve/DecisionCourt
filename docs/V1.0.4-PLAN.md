### 1.3 Trace 数据模型（后端聚合）

```go
// backend/internal/trace/parser.go

type Run struct {
    RunID       string                 `json:"run_id"`        // unique
    TraceID     string                 `json:"trace_id"`      // group
    SessionID   string                 `json:"session_id"`
    AgentType   string                 `json:"agent_type"`
    TaskType    string                 `json:"task_type"`     // "react_think" / "react_speak" / "react_rebuttal_retry"
    Model       string                 `json:"model"`         // "deepseek-v4-flash"
    Provider    string                 `json:"provider"`      // "deepseek"
    StartedAt   time.Time              `json:"started_at"`
    EndedAt     time.Time              `json:"ended_at"`
    LatencyMs   int                    `json:"latency_ms"`
    Status      string                 `json:"status"`        // "ok" / "error" / "retry"
    Input       map[string]any         `json:"input"`         // 截断后
    Output      string                 `json:"output"`        // 截断后
    ErrorMsg    string                 `json:"error_msg,omitempty"`
    RetryCount  int                    `json:"retry_count"`   // 0 = first try, 1+ = retry
    Tags        map[string]string      `json:"tags,omitempty"` // e.g. {"stance": "pro_a", "rejected": "true"}
}

type Trace struct {
    TraceID   string    `json:"trace_id"`
    SessionID string    `json:"session_id"`
    StartedAt time.Time `json:"started_at"`
    EndedAt   time.Time `json:"ended_at"`
    Runs      []Run     `json:"runs"`        // sorted by StartedAt
    Tree      RunNode   `json:"tree"`        // nested 父子关系
}

type RunNode struct {
    Run  Run       `json:"run"`
    Children []RunNode `json:"children,omitempty"`
}
```

**Trace 构造算法**：
- 同一 trace_id 的所有 runs 按 `StartedAt` 排序
- 父子关系：`RetryCount > 0` 的 run 是 `RetryCount-1` 的 child
- 没有 retry 的 run 是 root

```typescript
// frontend/components/courtroom/animations/AvatarAnimations.tsx

// 1. 律师 "说话中" — 点头 + 缩放
export const speakVariant: Variants = {
  initial: { scale: 1, y: 0 },
  speaking: {
    scale: 1.06,
    y: [0, -3, 0],          // 上下浮动循环
    transition: {
      scale: { duration: 0.3 },
      y: { duration: 0.6, repeat: Infinity, repeatType: "reverse", ease: "easeInOut" },
    },
  },
}

// 2. 律师 "思考中" — pulse + 微旋转
export const thinkVariant: Variants = {
  initial: { scale: 1, rotate: 0 },
  thinking: {
    scale: [1, 1.04, 1],
    rotate: [-1, 1, -1],
    transition: { duration: 2, repeat: Infinity, ease: "easeInOut" },
  },

// 3. 律师 "倾听中" — 静止但有 "点头回应"
export const listenVariant: Variants = {
  initial: { y: 0 },
  listening: { y: [0, 2, 0], transition: { duration: 3, repeat: Infinity } },
}

// 4. 调查员 "调查中" — 旋转放大镜
export const searchVariant: Variants = {
  initial: { rotate: 0 },
  searching: { rotate: [0, 15, -15, 0], transition: { duration: 1.5, repeat: Infinity } },

// 5. 法官 "敲锤" — 关键帧动画
export const judgeVariant: Variants = {
  initial: { y: 0, rotate: 0 },
  judging: {
    y: [0, -8, 0, 0],
    rotate: [0, -8, 8, 0],
    transition: { duration: 0.4, times: [0, 0.3, 0.6, 1] },
```

```
┌─────────────────────────────────────────────────────────────┐

│ └────────────────────────────┘                              │
│                                                              │
│ ┌────────────────────────────┐                              │
│ │ Run 2: 辩方律师 respond   │                              │
│ │   ... (树状展开)          │                              │
│ └────────────────────────────┘                              │
└─────────────────────────────────────────────────────────────┘
```

**AgentTraceNode.tsx**（单次调用卡片）:
- 标题: agent_type + task_type
- 时间: started_at → ended_at (latency_ms)
- Prompt 折叠展开
- Output 折叠展开
- Retry 折叠展示（每次 retry 一个子节点）
- 状态: ok / error / retry_failed

**BeliefDiffTimeline.tsx**（信念曲线）:
- 横轴: round / time
- 纵轴: 信念度 0-1
- 多线: 控方 / 辩方 / 调查员 / 法官 各自 belief_a + belief_b
- 突变点 hover 显示 belief_diff 来源（evidence / rebuttal）

**RebuttalTraceNode.tsx**（v1.0.2 反驳链）:
- 树状: 被反驳 evidence → rebutter evidence → 翻盘 evidence
- 颜色: standing=红 / overturned=绿

## 5. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| Framer Motion 在 SSR / Next.js 14 App Router 出错 | 庭审页崩溃 | `"use client"` directive + dynamic import + test mock |
| Trace 日志过大 (1 trial ~50 runs) | 加载慢 | LRU 缓存 + 日期分区 + 滚动归档 |
| 后端聚合慢 (一次拉 1 周 trace) | API timeout | 限制 date range + 分页 |
| 前端时间轴 60fps 掉帧 | 卡顿 | `transform: translateZ(0)` 启用 GPU + 减少 layout reflow |
| Framer Motion bundle +30KB | 首屏慢 | tree-shake + 按需 dynamic import |
