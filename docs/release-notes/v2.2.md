## 🆕 新增功能（v2.2 commit 汇总）

### P0-1: 气泡绝对定位（庭审横向滑动修复）

**根因**：AgentAvatar.tsx 气泡用 `absolute w-60 (240px)` 撑宽 grid cell，导致三列 grid 撑爆 max-w-3xl 中央 wrapper，整个庭审空间出现横向滚动。

**修复**：
- 气泡保持 `absolute` 定位（不占 layout 空间）
- 父容器保持 `relative`（提供定位上下文）
- 气泡相对于父元素定位，不会撑开庭审现场

**关键设计决策**：
- ❌ 之前改成 `relative` 定位 → 导致父容器被撑高，庭审现场页面跳动
- ✅ 保持 `absolute` + 父 `relative` → 气泡不占 layout 空间，不撑开庭审现场

### P0-2: 全局隐藏 scrollbar（庭审滑块丑修复）

**根因**：用户反馈"庭审现场滑块太丑了"。frontend 整个项目没有 `::-webkit-scrollbar` 自定义，滚动条走浏览器默认。

**修复**：globals.css 末尾追加全局 scrollbar 隐藏：
```css
* { scrollbar-width: none; }       /* Firefox */
* { -ms-overflow-style: none; }    /* IE / Edge legacy */
*::-webkit-scrollbar { display: none; width: 0; height: 0; }
```

**关联修复**：EvidenceBoard 改 grid wrap（见 P0-3）

### P0-3: EvidenceBoard 改 grid wrap（跟全局隐藏 scrollbar 一致）

**根因**：EvidenceBoard 原本 `flex overflow-x-auto` 横滚容器。globals.css 隐藏 scrollbar 后，用户看不到能横滚的提示，UX 反而更差。

**修复**：
- 改 `grid grid-cols-2 md:grid-cols-3`，自动 wrap
- 证据卡片 `w-64` → `w-full`（跟随 grid cell）
- 永远不出现横滚

### P0-4: 庭审记录文字渲染修复（MessageHistory + TrialReplay + RebuttalTraceNode）

**根因**：用户反馈"庭审回访对话流的文字渲染有问题"。

**修复**：
- MessageHistory `<p>` 加 `whitespace-pre-wrap break-words`（保留 LLM 输出 `\n\n` 段落）
- TrialReplay 对话流 `<p>` 加 `whitespace-pre-wrap break-words`
- RebuttalTraceNode rationale `<span>` 加 `whitespace-pre-wrap break-words`

**测试**：TrialReplay.test.ts 加 1 个 source-grep sub-test 验证 `whitespace-pre-wrap`

### P0-5: TrialHistoryList 防撑宽 + lucide Scale 图标一致化

**根因**：TrialHistoryList 之前：
1. `optionA/optionB` 极长时无 truncate，撑开整个 row，挤掉右侧按钮
2. `title` truncate 缺 `flex-1 + min-w-0`，在 flex 子项上不生效
3. `⚖` emoji 跟 CourtroomScene / TrialReplay 的 lucide `<Scale>` 图标不一致

**修复**：
- 外层加 `overflow-hidden`
- `title` 容器加 `flex-1 min-w-0`
- `optionA/optionB` 改 `max-w-[45%] truncate` 单行截断
- `⚖` emoji 升为 lucide `<Scale>` icon

### P0-6: dev compose Next.js rewrites（前端 404 修复）

**根因**：dev compose 缺反代层（prod 走 Caddy，dev 没有），导致浏览器 fetch `/api/v1/*` 直接打 Next.js dev server 自己 → 404。

**修复**（2 个文件）：
1. `frontend/next.config.mjs` 加 `async rewrites()`：
   - `/api/:path*` → `${BACKEND_INTERNAL_URL}/api/:path*`
   - `/ws/:path*` → `${BACKEND_INTERNAL_URL}/ws/:path*`
2. `docker-compose.dev.yml` 加 `BACKEND_INTERNAL_URL: http://backend:8080`

**关键**：`.env.local` 需手动加 `BACKEND_INTERNAL_URL=http://backend:8080`

### P0-7: 整个页面 h-screen 100vh（庭审记录面板高度修复）

**根因**：右侧庭审记录面板无限变高，没有高度限制。

**修复**：
- 最外层 `min-h-screen` → `h-screen`（固定 100vh）
- header 去掉 `sticky`，加 `shrink-0`（不被压缩）
- main content `h-[calc(100vh-64px)]` → `flex-1 min-h-0`（自动填充剩余空间）

**效果**：整个页面 = header + main content = 100vh，页面不滚动。右侧庭审记录面板在 main content 内部滚动。

## 📝 反思

### 触及 §2.1 裁决逻辑：**0**

v2.2 全部改动都是视觉 / 布局 / dev compose 修复，不动审判逻辑。

### v2.2 教训

1. **不要随便改 absolute 为 relative** — 气泡 absolute 是设计意图（不占 layout 空间），改成 relative 导致父容器被撑高
2. **docker 实测比 curl 冒烟有用** — 4 个 bug 都是浏览器实测发现的
3. **CRLF 治本要 dos2unix** — Edit 工具在 Windows 上会引入 CRLF，需要 `core.eol = lf` + `dos2unix`

v2.2 第一次实践验证了 AGENTS.md §11 Docker 业务测试规范：
